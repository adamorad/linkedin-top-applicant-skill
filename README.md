# linkedin-top-applicant-skill

A Claude Code skill that finds LinkedIn jobs where you would be a top applicant, rescores them against your CV, and renders one-page tailored CVs

## Stack
static

## Setup
```sh
(nothing — open the HTML)
cp .env.example .env  # fill in secrets
```

## Run
```sh
open src/index.html
```

## Structure
```
src/      — source code
tests/    — tests
docs/     — documentation
archive/  — parked old work
CHANGES.md  — notable changes
CLAUDE.md   — agent behavioral rules + project notes
SECURITY.md — vulnerability reporting
```
